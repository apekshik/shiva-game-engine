# Portfolio website

Vite + Three.js (vanilla JavaScript, no framework).

## Run

```sh
cd website && npm install && npm run dev
```

`npm run build` produces `dist/`; `npm run preview` serves it.

## Who owns what

`src/scene.js` is the Three.js hero scene (scene task); `src/content.js`, `src/sections.js` and `src/styles.css` beyond the reset are the content task; `src/main.js` and `index.html` wire them together.
